# 🏨 Smart Hotel Frontend

Smart Hotel Frontend is a modern web application that allows customers to interact with hotel/restaurant services digitally — from browsing menus to placing orders — while helping staff manage operations efficiently.

---

## 🚀 Overview

This frontend connects with the backend API to provide a seamless experience for:

- Customers → Order food, view menu, interact via table system  
- Staff/Admin → Monitor orders, manage tables, track alerts  

It focuses on **real-time interaction, simplicity, and usability**.

---

## 🎯 Problem

Traditional restaurant/hotel systems:
- Depend on manual order taking  
- Lack allergy awareness  
- Have no centralized digital interface  

---

## ✅ Solution

This application provides:

- 📱 Table-based digital ordering system  
- ⚠️ Allergy-aware ordering interface  
- 📊 Dashboard for staff to manage operations  
- 🔄 Real-time order tracking (pending → preparing → served)  

---

## 🧩 Key Features

- Table-based login system  
- Menu browsing & food ordering  
- Allergy input support  
- Order tracking system  
- Staff dashboard (orders, alerts, tables)  
- Role-based UI (admin / manager / user)  

---

## 🛠️ Tech Stack

- Frontend Framework: (React / Angular based on project)
- HTML5, CSS3, JavaScript / TypeScript
- REST API Integration
